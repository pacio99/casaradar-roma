# CasaRadar Roma

Interfaccia web statica per esplorare annunci immobiliari, ispirata ai portali di annunci e personalizzata per CasaRadar Roma.

## Avvio locale

Apri `index.html` direttamente nel browser. Non sono necessarie dipendenze o build.

## Pubblicazione su GitHub Pages

1. Crea un repository GitHub (ad esempio `casaradar-roma`).
2. Carica `index.html` e `README.md` nella cartella principale del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, seleziona **Deploy from a branch**.
5. Scegli il branch `main` e la cartella `/ (root)`, quindi salva.

Dopo la pubblicazione, GitHub mostrerà l'URL del sito nella sezione Pages.

## Stato attuale

Questa è una demo front-end autonoma. Gli annunci mostrati sono dimostrativi e non provengono da un feed reale. Ricerca, filtri, ordinamento, preferiti e dettagli funzionano nel browser, ma non c'è ancora un backend, un database condiviso o un collegamento API. I preferiti non sono sincronizzati tra dispositivi.

Prima di collegare una fonte reale, verificare che API, licenza e condizioni del fornitore consentano la visualizzazione e l'eventuale conservazione dei dati.
